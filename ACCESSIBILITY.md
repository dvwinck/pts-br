# Acessibilidade

## 1. Nosso compromisso

O objetivo do PTS-BR é um texto que o leitor entende numa leitura. Este objetivo também é um objetivo de acessibilidade. O projeto quer a especificação e o site acessíveis para todas as pessoas.

## 2. Escopo

- O site [dvwinck.github.io/pts-br](https://dvwinck.github.io/pts-br/).
- Os arquivos Markdown do repositório.
- As mensagens do linter e do plugin.

## 3. O que o projeto faz

- O texto da especificação segue as regras do PTS-BR: frases curtas, palavras com um significado e voz ativa.
- O site tem o modo claro e o modo escuro.
- O site tem uma busca em português.
- As tabelas têm uma linha de títulos.
- Os exemplos de comandos são texto, não imagens.

## 4. Ambientes compatíveis

- As versões atuais do Chrome, do Firefox, do Safari e do Edge.
- Leitores de tela com estes navegadores.
- Navegação com o teclado.

## 5. Limites conhecidos

- Algumas tabelas do 03 e do 04 são largas. Numa tela pequena, é necessário rolar a tabela.
- O projeto ainda não fez um teste completo com as WCAG 2.2.

## 6. Como informar uma barreira

1. Crie uma issue com o modelo "Erro".
2. Escreva "Acessibilidade" no título.
3. Escreva a página, o navegador, a tecnologia assistiva e o problema.

O mantenedor responde em até 10 dias úteis.

Documentação técnica que o leitor entende na primeira leitura

O PTS-BR é uma linguagem controlada para o português do Brasil. Ele tem regras de escrita, um dicionário com 1 significado para cada palavra e uma política para os termos técnicos.

Leia as regras Busque uma palavra no dicionário

A estrutura do PTS-BR segue o ASD-STE100. O PTS-BR não é uma tradução oficial e não tem aprovação da ASD.

R4.2 Frase de procedimento: no máximo 20 palavras

Não aprovado · 27 palavras

Antes de iniciar a atualização do cluster, verifique se todos os nós estão com o status Ready e se não há pods em estado Pending no namespace.

PTS-BR · 9 e 11 palavras

  1. Verifique se todos os nós estão no estado Ready.
  2. Verifique se o namespace pagamentos não tem pods no estado Pending.

Por onde começar

Se você escreve

  1. Leia a introdução (parte 01).
  2. Se você escreve procedimentos ou avisos, leia as seções 5 e 7 das regras.
  3. Compare um texto antes e depois nos exemplos (parte 06).
  4. Execute o linter no documento.
  5. Corrija cada alerta, ou escreva a justificativa no pedido de revisão.

Se você revisa

  1. Faça a trilha do revisor (parte 05, seção 9).
  2. Aplique a lista de verificação em cada revisão (parte 05, seção 4.2).
  3. Classifique cada desvio como S1, S2 ou S3 (parte 05, seção 4.3).
  4. Registre cada desvio neste formato: [S2][R4.2][ABERTO] descrição

Verifique um texto com o linter

O linter é um script do Python 3.9 ou de uma versão mais nova. Ele não precisa de instalação. Execute os comandos na pasta do repositório.

# Regras com verificação automática
python3 tools/check_spec.py docs/meu-documento.md
# Palavras sem entrada no dicionário (03) e nos termos técnicos (04)
python3 tools/check_spec.py --lista-branca docs/meu-documento.md
# Mensagens de interface em JSON ou .po
python3 tools/check_spec.py --mensagens locales/pt-BR.json

NOTA O linter em Python é a referência da versão 1.0.0. As regras desta versão ainda não têm resultado com o Vale. A lista branca verifica a forma das palavras. O revisor verifica o significado.

Use o PTS-BR no Claude Code

O plugin pts-br escreve, revisa e ativa o padrão PTS-BR no Claude Code. Para instalar o plugin, execute estes comandos no Claude Code:

/plugin marketplace add dvwinck/pts-br
/plugin install pts-br@pts-br

/pts-br:escrever

Escreve ou reescreve um texto técnico em PTS-BR. Antes da resposta, executa o linter no texto.

/pts-br:revisar

Avalia um texto, classifica os desvios em S1, S2 e S3 e mostra o resultado da revisão.

/pts-br:adotar

Ativa o PTS-BR nas respostas do Claude Code até o fim da sessão. Para todas as sessões, use /output-style com a opção PTS-BR.
